我的持仓 · 列表交互规范

目标：列表在「实时刷新」和「搜索过滤」时都不跳动、不闪烁、不塌白、不出现重复表头。每条含「怎么做 + 为什么」。总览页 / 证券账户页一致。

一、列表防跳动

  1. ✗ 不要用「每组固定高度 + 内部滚动」来防跳动。
    为什么：外层页面本身就是滚动容器，再套一个（甚至每个分组各一个）固定高度内滚区 = 嵌套滚动 —— 滚轮 / 触控板会被内层「吃掉」、滚动被截断，很难受；而且持仓是页面主内容，不该被塞进一个小滚动窗口里看。
    改用：列表按自然高度铺开、随整页一起滚；确需防跳动时靠滚动锚定（overflow-anchor:auto）或单元格原地更新（按代码 diff、只改数值/涨跌色、不重建行），而不是锁死高度。
    唯一例外：产品定位是专业交易终端（密集多面板并排）时，才考虑「整张表一个滚动区 + 表头吸顶 + 行虚拟化」——也是整表一个滚动区，绝不是每个分组各一个。

二、搜索过滤

  1. 只过滤不重建（隐藏不匹配行）。
  2. 隐藏必须用 class（.hh{display:none!important}），禁止 el.style.display=''。
    行是 inline display:grid、分组头是 display:flex；display='' 会抹掉它们退回 block，单元格竖着堆叠→清空搜索后列表塌白错位。class 隐藏不碰 inline display，恢复即原样。
  3. 搜索时隐藏两条「市值」分组头（含吸顶镜像），走扁平列表；清空恢复。
    分组头是整组总额，对过滤结果是误导；按结果重算又会随按键闪烁。
  4. 空组整段隐藏；两市场都无命中显示单条「无匹配持仓」。
  5. 搜索时列表定成「固定高度 + 内部滚动」（≈可视高 60%），不用 min-height 预留全高。
    高度恒定→不跳动；又不在页面里留可滚大空白（预留全高会「滑到底整屏空白」）。

三、吸顶「精简条」（滚动时顶部的 tab/搜索/表头/分组头）

  1. 滚进持仓、真实标题行滚出顶部后才显示。
  2. 整个列表都滚过吸顶线后（底部也在线之上）→ 收起，别压在后续内容上。
  3. 搜索态整条隐藏。搜索时列表已定高内滚、真实表头就在眼前，再吸顶一条就是两套表头重叠（重复）。
  4. 过滤/清空后主动重算一次显示状态（否则可能残留为「显示」压在内容上）。

四、联调验收清单

  1. ☐ 轮询：行序不变、只数字/涨跌色原地变，不闪不跳
  2. ☐ 新成交：出提示条，点击才并入，不自动插行
  3. ☐ 搜索：过滤不重建、两条市值头消失走扁平、空组隐藏、无命中提示
  4. ☐ 搜索再清空：列表完整复原，无塌白/错位
  5. ☐ 搜索中：整块高度不变（不跳动）、滑到底不是整屏空白
  6. ☐ 吸顶条：滚进才现、滚过收起、搜索态不现（无重复表头）
  7. ☐ 总览页 & 证券账户页表现一致
